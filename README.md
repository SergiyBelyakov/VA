# Сайт Валентини Рокун

Статичний сайт українською мовою. Завантажте весь вміст архіву в кореневу папку хостингу. `index.html` є головною сторінкою, `services/index.html` містить чотири послуги й ціни. Папка `assets` має лежати поруч із головним файлом.

Запис організовано телефонним посиланням `tel:+380974504433`. На сайті немає форми, календаря чи збору персональних даних. Після публікації перевірте дзвінок на мобільному пристрої й телефон, вартість та адресу з Валентиною.

Вартість із наданих скріншотів: індивідуальна й підліткова терапія 1700 грн; парна й сімейна 2300 грн. Тривалість кожної 60 хвилин, онлайн та очно. Сайт показує застереження, що ціну слід підтвердити перед записом.

Портрети надані користувачем. Чотири атмосферні зображення послуг створені для цього сайту. Вони ілюструють теми й не зображують реальних клієнтів або кабінет психологині.

Для власного домену додайте абсолютний canonical URL і абсолютний URL соціального зображення у метаданих обох сторінок.
