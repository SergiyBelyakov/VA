# Сайт Валентини Рокун — valentyna-rokun.com

Статичний сайт українською мовою. Cloudflare Workers Builds публікує гілку `main` у проєкт `va`. Файл `.assetsignore` визначає, які файли отримує відвідувач.

Основна адреса сайту https://valentyna-rokun.com/. Запити з `www` та з HTTP основного домену отримують відповідь 301 зі збереженням шляху й параметрів. Тестова адреса `workers.dev` повертає заголовок `X-Robots-Tag: noindex`.

## Структура
- `index.html` — головна
- `services/index.html` — огляд послуг і цін
- `services/individual/`, `services/teen/`, `services/couple/`, `services/family/`, `services/zhinoche-kolo/` — окремі сторінки послуг
- `assets/site.css` — єдиний файл стилів; `assets/*.webp` — зображення (для кожної ілюстрації є версія `-640` для мобільних, `srcset`)
- `assets/og-image.jpg` — картинка для соцмереж 1200×630
- `robots.txt` містить адресу `sitemap.xml`. Карта сайту перелічує канонічні сторінки й основні зображення. Після суттєвої зміни тексту, зображень або структурованих даних оновіть `lastmod` відповідної сторінки.

Портрети й фото гри надані замовницею. Чотири атмосферні ілюстрації послуг створені для сайту й не зображують реальних клієнтів або кабінет. Канонічні URL та OG-зображення абсолютні (`https://valentyna-rokun.com/...`) — за зміни домену оновіть їх у всіх сторінках і в `sitemap.xml`.
